# 퍼블리 트래픽 (단품 툴)

퍼블리에서 **트래픽 유입** 기능만 떼어낸 독립 단품 툴. 판매/대여용.
아이엠마케터식 **컴팩트 사각형 창 + 세로 스크롤** UI, 하단 **실시간 대여 카운트다운 + 만료 잠금**.

> 현재 단계: **디자인(UI/레이아웃) 틀** (`index.html`). 기능(검색 유입·체류·액션 등)은 이후 이식.

## 대여/라이선스 구조 (중요)

```
관리자 컨트롤타워(별도 웹, 나만 접속)
   └─ 고객추가·툴별 기간설정·사용료 기록
        ↓ (만료일 기록)
   공유 Supabase  licenses 테이블  (고객·툴·만료일·사용료·상태)
        ↓ (읽기만)
   각 툴(트래픽 등) — 하단 카운트다운 + 만료 잠금
```

- **이 툴은 "읽기"만 한다.** 실행 시 로그인 고객의 라이선스(만료일)를 **서버시간 기준**으로 읽어 하단에 실시간 카운트다운을 표시하고, 만료되면 자동 잠금.
- **기간 발급/연장·사용료 입력은 이 툴에 넣지 않는다.** 오직 별도 **관리자 컨트롤타워**에서만 (고객 조작 방지).
- **시계 조작 방지**: 남은 시간을 로컬 시계로 계산하지 않고 Supabase 저장 만료시각 + 서버시간 기준으로 판정, 주기적 재확인.

## 형제 제품(예정 · 같은 틀·같은 백엔드)
1. 서이추 + 공감·댓글
2. 트래픽(플레이스 + 맵)  ← **이 레포**
3. 스마트스토어 + 네이버쇼핑
4. 블로그 트래픽 (별도)
